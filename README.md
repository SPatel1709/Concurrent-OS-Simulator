# Concurrent OS Simulator

A collection of Operating Systems implementations in C/C++ covering process scheduling, synchronization, multithreading, deadlock handling, and virtual memory.

The repository contains multiple independent OS lab implementations grouped together because they explore related systems concepts using Linux APIs and concurrency primitives.

## Implemented Components

### 1. Process Scheduling Simulator
Implemented a priority-based Round Robin scheduler using multiple Unix processes.

Key features:
- Shared ready queue and Process Control Blocks
- Priority-dependent time quanta
- CPU and I/O burst simulation
- Voluntary and involuntary context switches
- Timer-driven preemption using `SIGUSR1`
- System V shared memory and semaphores
- `fork()`, `exec()`, and signal handling

Folder:
`Semaphores_SharedMem/`

---

### 2. User-Level Synchronization Primitives
Implemented condition-variable style synchronization using System V semaphores and shared memory.

Supported operations include:
- lock / unlock
- wait
- signal
- broadcast

The implementation demonstrates conditional waiting, shared-state synchronization, and user-level synchronization behavior.

Folder:
`Synchronization/`

---

### 3. Pthread Dependency Scheduler
Implemented a multithreaded dependency-driven task executor using POSIX threads.

Key features:
- DAG-based task dependencies
- Worker threads
- Per-worker condition variables
- Shared mutex protection
- Barriers for phase synchronization
- Dependency-triggered wakeups

Folder:
`Pthread_API/`

---

### 4. Deadlock Detection and Recovery
Implemented a multithreaded resource manager with multiple resource types and concurrent worker requests.

Key features:
- Resource allocation and release
- Waiting queues for blocked requests
- Deadlock detection using finish-sequence analysis
- Greedy victim selection
- Resource preemption and recovery
- Worker-specific condition variables

Folder:
`DeadLock_Detection/`

---

### 5. Demand Paging with LRU Replacement
Implemented a virtual-memory simulator using demand paging and local LRU page replacement.

The workload simulates memory accesses generated by a 1920×1080 image-processing task.

Key features:
- 4 KB pages
- Configurable number of physical frames
- Page table for resident-page lookup
- Doubly linked list for LRU tracking
- O(1) page lookup and LRU updates
- Six different RGB memory-layout schemes
- Measurement of page faults, fault rate, and estimated access time

Folder:
`LRU_Demand_Paging/`

---
